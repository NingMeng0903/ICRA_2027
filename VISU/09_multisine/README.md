# 09_multisine — 论文方法多正弦 Gv

采集：`20260903_195045` · filter OFF · 力环关 · 峰值 15 mm/s · 0.2–10 Hz · 3×20 s · 中位 · `vel_ff → v_ach`

## 结论

- **T0 = 28.0 ms，和 03 相同。** Γd = 6。论文激励和 log chirp 锁在同一档延迟。
- Tp = 20 ms、K = 0.882 **不要换掉 03 的 14 ms / 0.960。** 多正弦把约 196 条线叠到峰值 15 mm/s，RMS 只有 4.2 mm/s（03 chirp 是 10.6）。0.3–8 Hz 相干中位 0.94、最低 0.85（03 是 0.98 / 0.95）。|G| 被低估，拟合就把 Tp 拉长。
- 有效带仍是 0.3–8 Hz。时域 xcorr = 45 ms **不是 T0**。
- 植物没变。名义 Tn 继续用 03：**28 + 14，K ≈ 0.96**。09 只交叉验证延迟。
- 不必换姿再采。不要写 yaml。
